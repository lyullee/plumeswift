# PlumeSwift 개발 기록과 검증 인계

이 문서는 첫 공개 시점의 기술적 변경과 비교 범위를 정리한다. 로컬 연구 작업은 단일 초기 스냅샷으로 공개하며, 아래 기록은 그 이전 작업을 검증 유형별로 복원할 수 있도록 남긴다.

## 비교 결과와 경계

- FFI 7개 조건·210개 센서에서 최적화 전후 및 Python 병렬/순차 농도와 질량수지는 일치했다. 이 비교의 실측 대비 Python RMSE는 1.9843 %p, 원본 CPU 비교는 1.9655 %p였다.
- GLE 가속의 단일 FFI Test 5에서는 같은 Linux 환경의 한 CPU에서 Python 20.39초에서 14.97초로 감소했다. C++는 14.06초였다. 최적화 전후 네 시점의 입자 좌표 최대 차이는 3.73e-12 m였고, 같은 시드의 가속판 반복 실행에서 기록한 상태는 비트 단위로 같았다.
- 7개 조건을 같은 Linux CPU 범위에서 실행한 단일 측정에서 Python 순차 231.9초, Python 사례별 5워커 78.1초, Python 사례 내부 보간 5워커 269.3초였다. 대응 C++ 결과는 207.4초, 92.9초, OpenMP 5스레드 152.0초였다. 출력 작업이 달랐으므로 이 시간은 해당 실행 전체의 결과다.
- 4 vol% 이상인 실측 평균 센서 9개 중 2개를 포착했다. 지면 열전달, 독립 액적·풀, 압축성 플래싱, 밀도 피드백 및 연소가 필요한 질문에는 별도 모델 검증이 필요하다.
- 정적 WRF 자료, 실시간 교환 계약, CUDA 및 OptiX의 상태는 구성요소마다 다르다. 원본과 확인된 케이스와 남은 차이는 해당 JSON에서 확인한다.

## 재실행 체크리스트

1. Python·OS·NumPy·SciPy·Numba·GPU 버전, 실행 옵션과 시드를 저장한다. 원본 참조는 [QES v2.3.1 고정 커밋](https://github.com/UtahEFD/QES-Public/tree/dced7ec571487be7538eca17bfc25bb3262fb6d0)으로 맞춘다.
2. [사용 설명서](USER_GUIDE.md)에서 먼저 외부 입력 없이 설치 시험을 실행한다. 원본 비교는 풍장, 입자 단일 스텝, 농도 순으로 범위를 확대한다.
3. FFI 원 보고서의 Appendix A 농도 평균과 유량·기상 조건을 문서의 열 이름에 맞춰 준비한다. 평균농도와 최대농도, 측정 시간과 계산 창, 풍향 FROM과 TO를 구분한다.
4. 입력과 물성표에 해시를 기록하고 모델별로 원시 예측 CSV·환경·시간 로그를 따로 보관한다. 고농도 센서 포착률, RMSE, 질량수지와 원본 대비 차이를 각각 계산한다.
5. 모델 방정식·수치 풀이·실행 경로를 한 번에 하나씩 바꾼다. 정밀도나 난수 스트림을 변경하면 같은 경로 반복 재현과 다른 경로 비교를 별도로 기록한다.

공개 저장소에는 집계된 비교 근거를 포함한다. 외부 논문 PDF, 측정 원자료, 사설 사례, 원본 C++ 체크아웃 및 대용량 NetCDF는 원 제공처 및 라이선스에 따라 따로 확보한다.
