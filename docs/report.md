# QES 실행 결과 및 공개 검증 데이터 검토

검토일: 2026-11-06, 한국 시간.

QES v2.3.1 원본을 C++/CUDA로 빌드해 실제 계산했다. QUIC은 기관 배포본이 없는 상태에서 사용자가 QES 우선 진행을 선택했으므로 실행하지 않았다.

## 이번 실행에서 확인된 내용

| 항목 | 실제 결과 | 해석 범위 |
|---|---:|---|
| 균일 흐름, x/y 두 방향의 질량유량 | 1 g/s 입력 대비 최대 오차 약 0.26% | 기본 수송·질량보존 점검 |
| CPU/GPU 바람장 차이 | 성분별 최대 약 5.4e-5 m/s | 같은 입력에서 두 솔버의 수치 일치 |
| 작은 영역 100×100×50 m, 장애물·풍향·풍속 변경 | 전체 계산 약 2.2–4.3초 | 240초 물리시간, 24,000 입자 방출 |
| EPA 77개 건물, 400×400×60 m, 600초 방출 | 전체 약 33.4초 | 120,000 입자, 초기 평균 제외 540초 |
| EPA 농도 수집 세분화, 1,200초 방출 | 전체 약 126.9초 | 240,000 입자, 900초 평균, Courant=0.1 |
| MUST 형상 120개 컨테이너 | 약 21.2초 | 바람·난류·파일출력 포함. 확산은 미실행 |

시간은 각 컨테이너 내부 Python이 QES subprocess를 실행한 뒤 종료까지 측정한 wall time이다. 이미지 다운로드·빌드·Docker 시작 시간은 포함하지 않는다. 이 표는 동일 조건의 일반 CFD와 직접 비교한 속도비가 아니다. 실행 로그·명령은 `results/qes/*/execution.json`에 남겼다.

작은 장애물 케이스에서 오류 입자가 19개/24,000개(약 0.079%), 빠른 바람에서는 47개/24,000개(약 0.196%) 발생했다. 따라서 그림이 생성됐다는 사실과 모든 수치 점검을 통과했다는 사실을 구분한다. 단면 질량유량 시험은 오류 입자가 없는 별도 균일 흐름에서 수행했다.

## 실측 풍동 데이터: BROWN2000 / EPA 7×11

개발진이 공개한 원시 TXT, 원 보고서, MATLAB 자료, 형상 shapefile을 확보했다. 77개 정육면체 장애물과 ethane 추적가스 실험이다. 실험 mm 좌표를 100배 확대한 모델 m 좌표로 변환했다.

- x_model = 50 + 0.1 × x_experiment_mm
- y_model = 200.5 + 0.1 × y_experiment_mm
- z_model = 0.1 × z_experiment_mm
- 건물 높이 H = 15 m, 기준풍속 U_H = 2.83 m/s
- 무차원 농도 K = C × U_H × H² / Q, Q = 1 g/s

바람장 격자는 2×2×1 m이다. 농도 수집 격자는 2×2×0.2 m로 바꿔 지면 0.1 m의 실험 샘플 높이에 맞췄다. **수집 격자를 세분화해도 바람장 해상도가 0.2 m가 되는 것은 아니다.**

| 비교 | 표본 수 | RMSE |
|---|---:|---:|
| U 수직 프로파일 | 894 | 0.429 m/s |
| V 수직 프로파일 | 839 | 0.0525 m/s |
| W 수직 프로파일 | 2,074 | 0.222 m/s |
| 양의 배경 보정 측정 농도 K | 524 | 0.337, 무차원 |

농도 FAC2는 **45.6%**다. FAC2는 예측이 측정의 0.5–2배 범위에 들어온 비율이다. 농도 평균은 실측 K=0.164, 예측 K=0.0895로, 이번 설정에서는 평균을 낮게 예측했다. FAC2 계산에서는 배경 보정 후 0 이하인 측정값만 제외했다. 격자 밖으로 외삽하거나 실측값에 맞춰 결과를 정규화하지 않았다.

세분화한 시험에서 오류 입자는 24/240,000개, **0.01%**였다. 작은 비율이지만 손실을 기록했고, 이는 탐색적 비교이지 완전한 질량보존 또는 검증 통과의 증거가 아니다. 입자 무작위성·격자·경계조건·난류 모형에 대한 불확실성 평가를 아직 수행하지 않았다.

현재 결과로 '적분모델보다 항상 정확하다'거나 'CFD 정확도를 확보했다'고 결론 낼 수 없다. 장애물 공간분포는 표현하지만 농도 정밀도에는 개선이 필요하다.

출처: [QES-Plume 논문 및 공개 실측 데이터](https://gmd.copernicus.org/articles/16/5729/2023/), [QES 저장소](https://github.com/UtahEFD/QES-Public).

## 발견한 QES 옵션 문제

공개 EPA 예제의 `streetCanyonFlag=2`를 사용하면 초기 v0 일부가 NaN이 되고 최종 바람장 대부분이 NaN으로 퍼졌다. CPU와 GPU에서 모두 재현됐다. 프로그램 종료 코드는 0인데 120,000개 입자 전부가 rogue 처리되는 사례도 확인했다.

`streetCanyonFlag=1`과 `0`에서는 유한한 바람장이 생성됐다. 실제 풍동 비교는 옵션 1로 진행했다. 원본 솔버 코드는 바꾸지 않았고 실패 사례를 `epa_array_s1/s3`, 수정 옵션을 `epa_canyon1`, 최종 비교를 `epa_sampling`으로 분리해 보존했다. `scripts/verify_results.py`는 원본 문제 검출과 수정 사례의 유한성 검사를 구분한다.

## 공개 CFD: PPMLES / MUST

200개 기상조건의 LES 데이터가 공개돼 있다. 전체 자료는 약 36.5 GB이다. 이번에는 기상조건 200개와 탐침 좌표, 격자 노드 좌표, LES 1번의 세 인덱스 구간에서 각 256개 노드의 c/u/v/w를 확보했다. 선택 필드에 약 7.9 MB, 전체 x/y/z 좌표에 약 46.1 MB의 HTTP Range 전송을 사용했다.

격자의 지붕 노드로 120개 컨테이너의 반복 형상과 위치를 검증했다. 컨테이너 크기 2.42×12.2×2.54 m, x 간격 15.32 m, y 간격 20.1 m이다. QES 모델 좌표에는 (85,175,0) m를 더했다. LES 1번의 유입각 -30°, u*=0.3452 m/s, z0=0.045 m를 사용했다. QES 풍향은 기상학적 '불어오는 방향' 300°로 변환했다.

768개 선택 노드 중 z≥0.5 m이고 보간 가능한 629개를 비교했다.

| 비교 | 결과 |
|---|---:|
| 속도 크기 RMSE | 0.757 m/s |
| 속도 벡터 RMSE | 1.045 m/s |
| 속도 크기 FAC2 | 92.5% |

**한 LES 조건의 편의 표본**이며 전체 영역·전체 200조건의 성능을 뜻하지 않는다. 바깥 경계와 격자도 LES와 다르다. 농도 소스와 농도 출력의 직접 비교는 아직 수행하지 않았다. LES 통계와 실증 데이터는 서로 다른 근거다.

출처: [PPMLES 원본 데이터](https://zenodo.org/records/11394347), [자료 생성 논문](https://doi.org/10.1016/j.dib.2025.111285).

## 액화수소와 다른 가스 자료

실행·다운로드·적합성 판정을 혼동하지 않도록 구분했다.

| 자료군 | 확보 상태 | 이번에 수행한 범위 |
|---|---|---|
| PRESLHY E3.5, LH2 공급 25회 누출 캠페인 | 원시 엑셀 24개 공개 목록 확인, trial 10 다운로드 | 5개 센서 시트 검토·CSV 추출·신호 그림 생성. 다른 파일은 서버 429/시간초과 |
| PRESLHY E3.1B | 12회 저온 방출 메타데이터 확인 | 소스항 검증 후보 검토 |
| ELVHYS 4.1 | 3회 시험, 11개 파일 다운로드 | 용기 증발/산소 농축 실험으로 분류. 실외 확산 시험으로 제외 |
| USN H2 채널 | 22개 ZIP+README 다운로드 | 원본 체크섬·ZIP CRC·CSV 구조 확인, 29개 농도 센서 자료 |

| 액화 암모니아 FLADIS / Desert Tortoise | 보고서·다중모델 논문 확인 | 기계 판독 원시 데이터 미확보, 향후 후보 |

**LH2 판단:** 실험 캠페인의 공급원이 액체라고 해서 모든 노즐 출구가 액체 상태인 것은 아니다. PRESLHY는 배관 열유입과 2상 흐름을 함께 다룬다. QES가 이런 물리를 제공하는 것처럼 상온 수동 추적가스로 바꿔 검증하지 않았다.

HyRAM의 Friedrich 조건은 36–43.59 K로 수소 임계온도보다 높다. 이 저온 수소 제트 검증을 LH2 액상 누출 검증으로 표시하지 않았다. HyRAM과 QES의 실제 물리 결합은 아직 없다. HyRAM은 제트 근접장을 다룰 보조 후보로만 실행했다.

ELVHYS 4.1의 README는 100 L 용기의 액화수소 증발과 공기 유입을 설명한다. 공개 META의 다른 서술·날짜와 파일명 사이에 불일치가 있어 기록했다. 일부 농도는 영점 보정 후 음수다. 음수를 임의로 0으로 바꾸지 않았다. H2SAFE의 `#N/A`도 0으로 치환하지 않고 누락값으로 유지했다.

Dataverse 자료와 확보한 PRESLHY 파일의 **35개 원본 체크섬이 모두 일치**했다. 이는 파일 무결성 확인이며 센서 정확도나 모델 물리의 검증은 아니다.

## 재현성 및 후속 판단

코드·Dockerfile·검토 목록·원시 자료·생성 XML·NetCDF·명령·로그·지표·그림을 프로젝트에 남겼다. `.gitignore`는 대용량 원본과 계산출력의 Git 추가만 제외하며 로컬 파일은 유지한다.

HyRAM은 처음 설치된 최신 SciPy에서 ODE 콜백 호환 오류가 났다. 별도 venv의 SciPy를 1.15.3으로 고정해 공식 10개 테스트를 재실행했고 모두 통과했다. 원본 HyRAM 코드 수정 없이 해결했다. 처음 실패한 로그도 보존했다.

이번에 만든 것은 **작동하는 빠른 3D 수동 추적가스 계산·검토 환경**이다. LH2 적용에는 다음 물리 작업이 남는다: 검증된 방출·열역학 소스항, 근접장 제트/증발 해석, 밀도·부력이 중요한 구간의 모델 선택, 이후 QES로 연결할 지점의 정의, 실험별 센서 좌표·시간·단위 일치. 이 작업을 마치기 전에는 실제 LH2 농도 또는 안전거리 정확도를 주장할 수 없다.
