# QES와 lyullee/slabx-lh2의 액화수소 정확도 검토

후속 업데이트(2026-11-07): 아래는 결합 구현 전 검토다. 이후 연구용 LH2 근사를 구현해 같은 FFI 센서 평균으로 직접 비교했다. [실행 결과와 제한](LH2_direct_benchmark.md)을 참조한다. 전체 정확도 개선에는 실패했다.

## 판단

**현재 구축한 QES가 SLABx-LH2보다 액화수소 누출을 더 정확하게 예측한다고 판단할 근거가 없다.** 이번 검토에서도 같은 LH2 시험에 대한 두 모델의 동일 조건·동일 통계 비교는 성립하지 않았다. QES의 장애물 해석 기능은 장점이지만, 현재 QES 수동 추적가스 구현에는 LH2 소스·상변화·부력 피드백이 없다.

현 단계에서 장애물이 지배하지 않는 LH2 누출의 비교 기준은 SLABx-LH2 쪽에 두는 것이 타당하다. 이는 물리 범위와 실험 근거의 판단이며, QES 대비 수치 우위를 실험으로 확정했다는 의미는 아니다. 장애물이 지배하는 상황에서는 두 방법의 기능 차이만으로 정확도 우열을 확정할 수 없다.

검토 소스:

- slabx-lh2 0.2.0, commit `1ef613102819de1c2feebd062aff3b49997e1927`.
- slabx 1.0.8, commit `820e368ba6454aad8627dac5967115d9648c80c7`.
- 기존 QES 2.3.1 계산·지표는 이전 결과를 유지했다. 이번에 LH2로 이름만 바꾼 QES 결과를 만들지 않았다.

## 직접 확인한 실행 결과

FFI-RAPPORT 20/03101의 공개 PDF를 확보해 Appendix A를 추출했다. 7개 야외 시험에서 **826개 센서 기록 = 농도 210 + 온도 616**을 얻었다. Test 2의 배치는 30/50/100 m 세 원호가 아니라 9.010/11.043/30 m여서 별도 취급해야 한다. 추출한 Test 4 농도표를 원 PDF와 시각적으로 확인했다.

이번 PDF SHA-256은 `c2fb0a8d07ebff0175fb386826682ef76a678c9df711bc705200a9e517ab9374`로 저장소 저자의 감사본 해시와 다르다. 따라서 바이트 단위 동일 원본이라고 표시하지 않았다. 추출 기록 수와 주요 농도·좌표·평균시간은 PDF에서 확인했다.

공개 패키지의 **기존 6개 시험 경로**를 재실행했다. 여기에는 Test 2가 없다. LH2 물성, 수분/얼음 보정, 공개 jet source, plume-width coupling, 원시 LFL 거리(safety_factor=1)를 사용했다. 상대습도는 FFI 공개 보고서에 없으므로 0/25/50/75/100%를 모두 계산했다. 관측값에 맞는 RH만 선택하지 않았다.

LFL 구간 일치는 RH 0/25/50%에서 각각 **3/6**, RH 75/100%에서 각각 **5/6**이었다. 두 수평 방출의 30 m 농도 과소예측은 계산한 모든 RH에서 유지됐다. 이는 공개 문서의 기존 6개 시험 결과를 재현한다.

이 표의 농도는 엄밀한 동일 통계 비교가 아니다. 관측은 센서 시계열의 시간 최대값 중 원호 최대값이고, `concentration_field(...).peak`는 해당 평균시간의 중심선 농도다. 이름이 `peak`여도 시간 순간최대 농도를 뜻하지 않는다. 따라서 이 표의 농도비를 MAE나 전체 농도장 정확도로 전환하지 않았다. 원호 LFL 구간도 제한된 센서 범위에서 얻은 것이며 연속적인 실제 경계의 정확한 위치가 아니다.

모델 계산 시간은 이 컴퓨터에서 시험당 약 0.4–0.7초였다. 이는 위 공개 6개 시험 경로의 값이다. README의 다른 컴퓨터·다른 연구 경로의 수십 ms와 섞지 않았다. QES와 영역·출력이 다르므로 직접 속도비를 만들지 않았다.

공개 코어 관련 테스트는 **135 passed, 5 skipped**였다. 대상은 physical_transition, source_ledger, water_ice, modules이다. 전체 테스트 실행은 문서 재현 subprocess를 포함해 오래 걸려 중단했으므로 전체 suite 통과라고 표시하지 않았다. 5개 skip은 테스트 로그에 남았다. 이후 같은 집합에서 ablation subprocess 하나를 제외한 실행도 134 passed, 5 skipped였다.

## 공개 README의 210개 측정값 성능은 별도 결과

저장소는 다음을 보고한다:

- 7개 시험, 센서-시험 기록 210개.
- MAE **0.086463 vol%**, RMSE **0.132241 vol%**, bias **-0.014593 vol%**.
- 2 vol% 분류는 명목상 **209/210**. 표시 자릿수 기준 210/210은 별도로 취급.
- 4 vol% 분류는 **210/210**.

이 수치는 **저자가 보고한 연구 결과**이며 이번에 재현한 수치가 아니다. `docs/61`과 `docs/62`는 재현에 별도 비공개 연구 capsule이 필요하다고 명시한다. 실행 환경은 slabx 1.0.6, editable slabx-lh2 0.1.4, lh2poolx 0.1.2였고, Tests 1/2/3/5/7에는 v1162, Tests 4/6에는 v1165 경로가 사용됐다. 공개 0.2.0/1.0.8 설치만으로 이 필드가 만들어지지 않는다.

따라서 다음을 구분해야 한다:

| 근거 | 확인 상태 |
|---|---|
| 공개 코드의 소스 계약·물성 보정·재고 질량 구분 | 코드 검토 및 관련 테스트 실행 |
| 기존 6개 시험의 LFL/원호 비교 | 공개 코드와 FFI 원문에서 재현 |
| 최신 7개 시험·210개 농도 예측 | 문서상 보고값. 정확한 연구 입력/예측 벡터/스크립트 미확보 |
| 현재 QES의 동일 LH2 시험 오차 | 없음 |

210개 기록은 210개 독립 누출 실험이 아니다. 한 캠페인의 7개 시험에서 나온 상관된 센서 관측이다. 같은 데이터에서 경로를 선택한 뒤 성능을 보고하면 일반화 성능과 구별해야 하며, 공개 자료에서 독립 holdout 성적을 확인하지 못했다.

원 보고서의 농도 평균을 기준으로 하면 4 vol% 이상인 기록은 **9/210**, 2 vol% 이상은 **24/210**이다. 시간 최대값으로 바꾸면 각각 35/210과 59/210이 된다. 따라서 'LFL 100%'를 해석하려면 예측 대상이 평균인지 최대인지, 양성/음성 수와 false-negative가 무엇인지 함께 봐야 한다. 저자가 제시한 전체 예측 벡터가 없으므로 연구 결과의 혼동행렬을 독립적으로 재구성하지 않았다.

또한 FFI 농도표의 평균구간은 Test 4: 25–300 s, Test 5: 200–325 s, Test 6: 20–140 s였다. 기존 공개 경로의 `averaging_window_s`는 각각 310/200/150 s이다. 이는 공개 경로로 센서 평균오차를 새로 계산할 때 먼저 맞춰야 할 차이이며, 비공개 연구 경로에도 같은 문제가 있다고 단정하지 않는다.

## QES와의 우열 판단

| 비교 기준 | 현재 QES 구현 | 검토한 SLABx-LH2 |
|---|---|---|
| 건물·장애물 주변 바람장 | 3D 경험식·질량보존으로 근사 | 지배적인 장애물/재순환은 적용 제외 |
| LH2 방출·저온 열역학 | 기존 구현에 없음 | 소스 계약·물성 보정·LH2용 인터페이스 및 경로 존재 |
| 증발·2상 흐름·부력 | 수동 추적가스 경로에 없음 | 경로별 범위와 제한이 있음. 공개 source adapter만으로 전체 물리가 자동 해결되지는 않음 |
| 동일 LH2 실험의 직접 비교 | 아직 없음 | 기존 6개 시험 재현, 최신 7개 연구값은 독립 재현 불가 |
| 수치적으로 더 정확하다는 결론 | 성립하지 않음 | QES 대비 우위 확정도 아직 불가 |

앞선 QES의 EPA 농도 FAC2=45.6%와 이 모델의 0.086463 vol% MAE는 가스·실험·측정통계·평가단위가 다르다. 숫자만 나란히 놓고 모델 순위를 매길 수 없다. MUST LES 바람장 RMSE도 LH2 농도 정확도를 뜻하지 않는다.

이번 판단은 **QES 단독으로 기존 LH2 모델을 교체할 실험 근거가 없다**는 것이다. 두 모델을 결합할 경우에도 SLABx의 소스 상태를 QES에 넘기는 인터페이스만으로 검증이 끝나지 않는다. 밀도·부력이 충분히 약해진 인계 지점과 보존량을 정의하고, 해당 가정이 실험에서 성립하는지 확인해야 한다.

## 정확도 개선을 입증할 비교 설계

1. 기존 210개 연구 경로의 정확한 입력, 센서별 예측, 센서 평균/최대 정의, 버전과 기상 처리를 고정한다. 공개 6개 경로를 최신 연구 경로로 표시하지 않는다.
2. 두 모델에 동일한 소스 또는 검증된 공통 소스 인계 상태, 기상 시계열, 형상, 물리시간을 입력한다. QES의 빠진 LH2 물리부터 보완한다.
3. 센서의 R/방위/높이를 실제 downwind/crosswind 좌표로 변환한다. 원호 반경 R을 모든 센서의 x로 사용하지 않는다.
4. 실험별 같은 구간의 평균과 최대를 각각 비교한다. PRESLHY 포화 센서는 임의의 확정값으로 쓰지 않고 중도절단/제외 규칙을 사전에 정한다.
5. 모델 선택에 사용하지 않은 PRESLHY 시험을 검증용으로 남기고, 시험 단위로 MAE/RMSE/bias/FAC2와 2/4 vol%의 false-negative를 보고한다. 공간 전체 LFL 경계는 센서가 제공하는 정보 범위에서만 판단한다.

현 공개자료만으로 이를 모두 충족할 수 없어서 이번에는 우월 정확도 수치나 QES 개선율을 만들지 않았다.
